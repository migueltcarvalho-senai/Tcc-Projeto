3. ANIMAÇÕES E COMPORTAMENTO DOS CARDS (PÁGINA PRINCIPAL)
--------------------------------------------------------------------------------
- Disposição em Zig-Zag:
  * Cards organizados em eixo horizontal alternando posições (2 ligeiramente
    elevados e 2 ligeiramente rebaixados).
- Inclinação Lúdica:
  * Cada card possui uma rotação inicial sutil (tortos/inclinados alternados
    entre esquerda e direita: -3.5deg, +3.5deg, -2.5deg, +2.8deg).
- Efeito Hover (Desentortar):
  * Ao passar o cursor do mouse (hover), o card se desentorta suavemente para
    rotação 0deg, elevando-se ligeiramente com física elástica (cubic-bezier) e
    aumentando de escala (scale 1.04).

5. DESENVOLVIMENTO DO PRIMEIRO JOGO: QUIZ DE INGLÊS (GAP FILL)
--------------------------------------------------------------------------------
- Arquivo Principal: jogo-ingles.php
- Estilo: css/jogo-ingles.css
- Mecânica do Jogo:
  * Formato "Complete the Sentence" (preencher lacuna).
  * A frase é dividida em 3 partes:
    1. Primeira parte da frase;
    2. Lacuna central ("gap" sublinhado e destacado);
    3. Segunda parte da frase.
  * Abaixo da pergunta, são exibidos cards interativos com opções de palavras,
    misturando a resposta correta com opções erradas (distratores).
  * Verificação Interativa:
    - Ao clicar em uma opção incorreta: a lacuna e o card ficam vermelhos,
      tremem com animação de erro e emitem aviso ("Try again!"), permitindo
      nova tentativa.
    - Ao clicar na opção correta: o card fica verde, a lacuna é preenchida
      com a resposta em verde, feedback positivo é exibido ("Correct! Well
      done!"), a pontuação sobe e o jogo avança automaticamente após 1.4s.
  * Barra de Progresso dinâmica exibindo porcentagem e número da questão.
  * Tela de Conclusão / Overlay Final:
    - Exibe mensagem com base no aproveitamento (troféu/emoji, parabéns);
    - Placar final com total de acertos;
    - Botões para reiniciar o jogo ("Play Again") ou voltar à página inicial.
- Randomização Dupla:
  * Ordem das perguntas: embaralhada no servidor via shuffle() em PHP a cada
    vez que a página é carregada ou reiniciada.
  * Ordem dos cards de resposta: embaralhada no cliente via algoritmo
    Fisher-Yates no JavaScript a cada pergunta.

6. BANCO DE DADOS E ARQUITETURA DE DADOS (MYSQL)
--------------------------------------------------------------------------------
- Banco de Dados: `tccdb`
- Conexão: config/config.php (host localhost:3308, usuário root)
- Script de Migração: banco/jogo_ingles_migration.sql
- Estrutura Relacional Criada:
  1. Tabela `Jogo`:
     - id (INT, PK, AUTO_INCREMENT)
     - nome (INT)
     - descricao (VARCHAR)

  2. Tabela `Pergunta`:
     - id (INT, PK, AUTO_INCREMENT)
     - primeira parte (VARCHAR)
     - resposta (VARCHAR)
     - segunda parte (VARCHAR)
     - Jogo_id (INT, FK referenciando Jogo.id)

  3. Tabela `Conjunto de respostas erradas`:
     - id (INT, PK, AUTO_INCREMENT)
     - nome do conjunto (VARCHAR)
     - conjunto (JSON contendo o array de respostas erradas)
     - Pergunta_id (INT, FK referenciando Pergunta.id)

- Integração PHP/MySQL:
  * Query com INNER/LEFT JOIN e Prepared Statement (segurança contra
    SQL Injection).
  * Decodificação nativa do campo JSON (`conjunto`) via json_decode() para
    misturar com a resposta correta.
